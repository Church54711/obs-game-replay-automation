Quick installation

Set it up once.

The installer detects standard OBS installations, requests UAC only when Program Files requires it, and asks for one replay-output folder.

  1. 1
    Close OBS Studio

    Scene migration is intentionally blocked while OBS is running.

  2. 2
    Download and extract the ZIP

    Use the latest stable package from this page.

  3. 3
    Run the installer

    Double-click Install OBS Game Replay Automation.cmd.

  4. 4
    Add the Lua script once

    In OBS, open Tools → Scripts and select the exact installed path shown by setup.

Updates without guesswork

You publish. GitHub delivers. Users stay in control.

Setup can enable a limited-privilege daily update check. It only notifies when a newer stable release exists. Installation waits for the user, refuses to run while OBS is open, verifies the release checksum, and preserves the existing configuration.

Existing installations before version 0.4.0 need one manual upgrade to receive the updater.

Before you install

Requirements

  • Windows x64 and an installed copy of OBS Studio
  • A scene containing Game Capture and Application Audio Capture sources
  • Replay Buffer configured in OBS and a Save Replay Buffer hotkey
  • Internet access to GitHub only for release downloads and optional update checks
